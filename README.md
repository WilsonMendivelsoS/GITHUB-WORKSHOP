# Taller de Git y GitHub — Semillero

Bienvenido y bienvenida al taller. Este repositorio es tu terreno de práctica: en lugar de solo ver teoría, vas a ir aprendiendo Git y GitHub haciendo cosas reales sobre este proyecto (crear ramas, subir cambios, abrir Pull Requests, hacer merge...) y el repositorio te va a ir respondiendo. Cada vez que completes un paso importante, algo va a pasar automáticamente: verás un mensaje de felicitación en la pestaña **Actions**, o un comentario en tu Pull Request. Esa es la señal de que hiciste bien el ejercicio.

## ¿Cómo está organizado esto?

```
docs/                     Guías teóricas, una por tema
EJERCICIOS.md             La ruta práctica que debes seguir, en orden
participantes/            Aquí vas a agregar tu propio archivo
.github/workflows/        Las automatizaciones que reaccionan a lo que hagas
```

## Orden sugerido

1. Lee `docs/00-instalacion.md` e instala lo necesario.
2. Lee `docs/01-fundamentos-git.md` para entender qué es un repositorio, un commit, etc.
3. Sigue `EJERCICIOS.md` desde el Ejercicio 0. Ese archivo te va diciendo cuándo leer cada guía de `docs/`.
4. No te saltes ejercicios: cada uno depende del anterior.

## Paso 0: haz tu fork

Antes de clonar nada, necesitas tu propia copia del repositorio:

1. Arriba a la derecha de este repositorio en GitHub, haz clic en **Fork**.
2. Crea el fork en tu cuenta personal.
3. Entra a tu fork (quedará en `https://github.com/TU-USUARIO/GITHUB-WORKSHOP`) y ve a la pestaña **Actions**. GitHub desactiva las automatizaciones por defecto en los forks, así que haz clic en el botón verde **"I understand my workflows, go ahead and enable them"**. Sin este paso, las felicitaciones automáticas no van a funcionar.
4. Ahora sí, clona **tu fork** (no el original) y sigue con `EJERCICIOS.md`.

## ¿Dudas?

Si algo no funciona como se explica aquí, revisa primero la pestaña **Actions** de tu fork para ver si hay algún error en rojo, y pregunta en el grupo del semillero.

¡Éxitos!
